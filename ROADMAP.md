# Roadmap

AutoCAD Mechanical Harness is working toward a trustworthy 1.0 release for deterministic 2D
mechanical CAD automation. This roadmap communicates direction, not delivery dates.

## Available now

- Typed MCP, CLI, and Engineer Desktop surfaces
- Deterministic geometry and ten mechanical feature families
- Preview, validation, approval binding, stale-revision rejection, and readback
- DXF comprehension, recognition, takeoff, audit, remediation, measurement, and calibrated
  raster intake
- SQLite persistence, writer leases, audit records, and pilot metrics
- Python COM reading and a secured C# named-pipe bridge
- Offline, property, contract, golden, fault, compatibility, and CI bridge gates
- Disposable-drawing AutoCAD Mechanical 2027/R26 acceptance evidence

## Before 1.0

- Publish reproducible, signed release bundles and checksums
- Validate a clean-workstation installation path
- Build a 30–50 case engineer-selected, legally publishable golden corpus
- Add independently calculated takeoff references and approved material/profile evidence
- Exercise representative workflows on more supported AutoCAD versions
- Complete production drawing pilots with explicit organizational approval
- Resolve the durable checkpoint-file replacement gap
- Document compatibility and migration policy for public contracts

## Community priorities

Useful contributions include:

- Synthetic golden drawings with analytic expected measurements
- Unsupported or ambiguous DXF entity fixtures
- Deterministic validation rules with standards references
- Installation and accessibility improvements
- Documentation for additional MCP clients
- Security review of approval, path, transport, and persistence boundaries

See [CONTRIBUTING.md](CONTRIBUTING.md) before starting a large change.
