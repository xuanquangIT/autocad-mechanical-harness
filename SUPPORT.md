# Support

AutoCAD Mechanical Harness is a community-maintained engineering preview.

## Where to ask

- Use [GitHub Discussions](https://github.com/xuanquangIT/autocad-mechanical-harness/discussions)
  for setup questions, design proposals, and usage ideas.
- Use [GitHub Issues](https://github.com/xuanquangIT/autocad-mechanical-harness/issues)
  for reproducible bugs and accepted feature work.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Before asking for help, run `uv run cad-harness status` and the smallest relevant test. Share
the adapter type, Python version, AutoCAD version when applicable, error code, and sanitized
steps. Do not attach customer drawings, secrets, approval tokens, or private paths.

## Support boundaries

The project does not provide Autodesk licenses, Autodesk binaries, company drafting standards,
production certification, engineering sign-off, or guaranteed response times. Maintainers and
contributors cannot validate a manufacturing decision from a screenshot or an unreviewed
AI-generated drawing.
