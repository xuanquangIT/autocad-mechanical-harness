# v0.2.0 - Engineering Preview

`v0.2.0` is the first consolidated engineering-preview release of AutoCAD Mechanical Harness.
It is intended for controlled evaluation by engineers on disposable drawing copies. It is not
a certified production system and the included AutoCAD bridge artifact is development-unsigned.

## Highlights

- 22 typed MCP tools for document inspection, deterministic planning, preview, validation,
  audit/remediation, measurement, takeoff, and calibrated raster intake.
- Real AutoCAD 2027/R26 C# bridge with secured per-user Named Pipe, bounded semantic reads,
  atomic execution, stable metadata, post-commit measurement, durable idempotency, and explicit
  unknown-state handling.
- Session undo rollback plus an authenticated durable whole-DWG checkpoint catalog and restore
  coordinator behind a default-off, live-evidence gate.
- Restart-safe SQLite jobs, audit chain, writer leases, remediation selection, takeoff reports,
  and short-lived plan/revision-bound engineer approvals.
- Hardened R25/R26 bridge packager and receipt-bound crash-recoverable installer.
- Hash-bound development corpus tooling plus cryptographically signed production evidence gates;
  public/generated fixtures cannot be mislabeled as engineer-approved production evidence.
- Complete MCP, bridge build, install, upgrade, uninstall, and existing-drawing connection guide.

## Release assets

- `cad_harness-0.2.0-py3-none-any.whl` - Python/MCP application.
- `cad_harness-0.2.0.tar.gz` - Python source distribution.
- `AutoCADHarness-R26.0-0.2.0.0-DEVELOPMENT-UNSIGNED.zip` - AutoCAD 2027/.NET 10
  bridge for controlled acceptance only.
- `SHA256SUMS.txt` - hashes for the downloadable assets.

The inner bridge bundle also carries its deterministic `SHA256SUMS.ps1`. Autodesk runtime DLLs
are never redistributed.

## Breaking upgrade notes

- Contract schema `1.12` and canonical plan-hash behavior require matching Python and bridge
  versions. Recompile plans and obtain fresh approvals after upgrade.
- Existing approval and rollback tokens are intentionally not reusable across changed plans,
  revisions, schemas, or deployments.
- Bridge `AppVersion` is `0.2.0.0`, with a new `ProductCode`; `UpgradeCode` remains stable.
- Do not run multiple active harness bundles. Close AutoCAD and use the receipt-bound installer
  to remove/upgrade owned versions.

## Honest remaining gates

- Organisation code-signing certificate, approved timestamp service, and signed installer policy.
- Clean-workstation signed install/upgrade/uninstall acceptance.
- Thirty to fifty engineer-selected production drawings, five independently reviewed real
  takeoffs, an approved company profile/material table, real shop scans, and an engineer pilot.
- Live crash-point evidence before durable whole-DWG checkpoint replacement is advertised by
  default. Session undo remains the verified live rollback path.
