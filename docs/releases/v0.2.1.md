# v0.2.1 - Engineering Preview

`v0.2.1` supersedes `v0.2.0`. It contains the same consolidated engineering-preview
capabilities plus a bounded Windows installer recovery fix discovered by the first GitHub
Actions run.

## Patch fix

After a fault-injected installer process exits, Windows security or indexing software can
briefly retain metadata access to the transaction-lock path. The installer now retries the
read-only alternate-data-stream inspection for at most 500 ms. It still fails closed if the
path remains unreadable and never skips identity, reparse, ADS, receipt, or ownership checks.

The exact crash-recovery case passes 10 consecutive runs and the complete installer suite
passes `41/41` before this patch release.

## Included capabilities

- 22 typed MCP tools and deterministic geometry/validation workflows.
- AutoCAD 2027/R26 C# bridge with secured Named Pipe, bounded reads, atomic execution,

- Engineer Desktop plan/revision-bound approval and restart-safe SQLite workflow state.
- Hardened R25/R26 packager, crash-recoverable receipt-bound installer, production evidence
  attestations, development corpus tooling, and safe MCP installation guidance.
