# v0.2.2 - Engineering Preview

`v0.2.2` supersedes `v0.2.0` and `v0.2.1`. It contains the consolidated engineering-preview
release plus the verified Windows installer recovery correction.

## Installer recovery correction

GitHub-hosted Windows runners exposed that PowerShell's `Get-Item -Stream` provider can return
`PATH_UNREADABLE` while inspecting quarantined DLL metadata after a fault-injected process exit.
Regular files now use a zero-access native Windows metadata handle with read/write/delete sharing
and `FileStreamInfo`; directories retain a bounded provider retry. Alternate streams, reparse
points, file identity, receipt inventory, and ownership continue to fail closed.

The exact crash-recovery scenario passes 10 consecutive runs and the complete installer suite
passes `41/41` locally before publication.
