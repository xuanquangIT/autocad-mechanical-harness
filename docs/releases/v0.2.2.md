# v0.2.2 - Engineering Preview

`v0.2.2` supersedes `v0.2.0` and `v0.2.1`. It contains the consolidated engineering-preview
release plus the verified Windows installer recovery correction.

## Installer recovery correction

GitHub-hosted Windows runners exposed a deterministic `MAX_PATH` boundary: the longest
fault-injected quarantine asset reached exactly 260 characters, so a raw `CreateFileW` metadata
query returned `PATH_UNREADABLE`. The installer now adds the extended-length prefix only inside
its native layer after accepting a canonical absolute local-drive path. Files and directories use
the same zero-access metadata handle with read/write/delete sharing and `FileStreamInfo`; a clean
directory's `ERROR_HANDLE_EOF` result is treated as an empty stream set. Caller-supplied UNC,
device, and extended paths remain rejected. Alternate streams, reparse points, file identity,
receipt inventory, and ownership continue to fail closed.

The exact crash-recovery scenario passes 10 consecutive runs, a dedicated 260-character-path
regression passes, and the complete installer suite passes `47/47` before publication.
